# Reload

# Este comando pode ser usado 3x seguidas, com o cooldown de 10 por usuário independente do canal.

Este comando é utilizado para recarregar todos os comandos do bot. Caso algum tenha sido atualizado e não precisa de um reinício completo.


## As formas de utilizar este comando são:

```text
    user: +reload 

    bot: Usuário, Os comandos foram recarregados com sucesso.
```

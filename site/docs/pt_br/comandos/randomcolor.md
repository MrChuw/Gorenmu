# Randomcolor

# Este comando pode ser usado 3x seguidas, com o cooldown de 10 por usuário independente do canal.

Este comando responde com o código HEX de uma cor aleatória e o link para uma imagem da cor.

## Todos os aliases disponíveis para Randomcolor são:
    - rc

## As formas de utilizar este comando são:

```text
    user: +randomcolor 

    bot: Usuário, #<HEX> <Nome da cor> <Link da imagem da cor>
```

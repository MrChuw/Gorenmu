# Randomline

# Este comando pode ser usado 3x seguidas, com o cooldown de 10 por usuário independente do canal.

Este comando seleciona uma mensagem aleatória dependendo das opções passadas.

## Todos os aliases disponíveis para Randomline são:
    - rl

## As formas de utilizar este comando são:

```text
    user: +randomline argumento

    bot: Usuário, resposta
```

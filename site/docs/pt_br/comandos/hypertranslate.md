# Hypertranslate

# Este comando pode ser usado 3x seguidas, com o cooldown de 10 por usuário independente do canal.

Comando baseado no [ravbug](https://www.ravbug.com/hypertranslate/) que serve para traduzir um texto em idiomas aleatórios dependendo da quantidade de vezes que o usuário pedir.

## Todos os aliases disponíveis para Hypertranslate são:
    - ht

## As formas de utilizar este comando são:

```text
    user: +hypertranslate 10 teste

    bot: Usuário, <algum texto aleatório.>
```

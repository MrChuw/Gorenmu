# Chance

## Este comando pode ser usado 3x seguidas, com o cooldown de 10 por usuário independente do canal.

Este comando gera e retorna uma porcentagem aleatória, representando uma chance entre 0% e 100%.

## Todos os aliases disponíveis para Chance são:
    - %



## As formas de utilizar este comando são:

```text
    user: +chance 

    bot: Usuário, 34%
```

# Imgur

# Este comando pode ser usado 3x seguidas, com o cooldown de 10 por usuário independente do canal.

Este comando gera links aleatórios do Imgur com 5 caracteres, que são de 2014 para trás, e usando imgur7 para links de 2014 até o presente.

## Todos os aliases disponíveis para Imgur são:
    - imgur7

## As formas de utilizar este comando são:

```text
    user: +imgur <quantidade de imagens>

    bot: Usuário, <link para a imagem ou link para um site com todas as imagens>
```

```text
    user: +imgur7 <quantidade de imagens>

    bot: Usuário, <link para a imagem ou link para um site com todas as imagens>
```

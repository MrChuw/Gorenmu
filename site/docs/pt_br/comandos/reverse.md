# Reverse

# Este comando pode ser usado 3x seguidas, com o cooldown de 10 por usuário independente do canal.

Este comando reverte o texto enviado.

## Todos os aliases disponíveis para Reverse são:
    - invert

## As formas de utilizar este comando são:

```text
    user: +reverse o texto enviado.

    bot: Usuário, .odaivne otxet o
```

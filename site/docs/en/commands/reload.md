# Reload

# This command can be used 3 times in succession, with a cooldown of 10 per user independent of channel.

This command is used to reload all bot commands. If any have been updated and don't require a full restart.


## The way to use this command is:

```text
    user: +reload 

    bot: User, the commands have been successfully reloaded.
```

# Imgur_repeated

## This command can be used 3 times in succession, with a cooldown of 10 per moderation.

This command is simple; it counts all the images that have been generated by [imgur](imgur.md).



## The way to use this command is:

```text
    user: +imgur_repeated 

    bot: User, Total number of repeated images: <Number of repeated images> || Images: <Link to the images>
```

# IsAfk

## This command can be used 3 times in succession, with a cooldown of 10 per user independent of channel.

This command checks if a user is AFK or not.


## The way to use this command is:

```text
    user: +isafk user2

    bot: User, @user2 is not AFK.
```

```text
    user: +isafk user3

    bot: User, @user3 is AFK.
```

```text
    user: +isafk user4

    bot: User, @user4 is AFK and left a note: <message>
```

# Upsidedown

# This command can be used 3 times in succession, with a cooldown of 10 per user independent of channel.

This command reverses and turns the provided text upside down.

## All the alias available for Upsidedown are:
    - updown

## The way to use this command is:

```text
    user: +upsidedown tests

    bot: User, sʇsǝʇ
```

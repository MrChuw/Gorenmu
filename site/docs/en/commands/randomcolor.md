# Randomcolor

## This command can be used 3 times in succession, with a cooldown of 10 per user independent of channel.

This command responds with the HEX code of a random color and a link to an image of the color.

## All the alias available for Randomcolor are:
    - rc



## The way to use this command is:

```text
    user: +randomcolor 

    bot: User, #<HEX> <Color Name> <Link to the color image>
```
